# Aster Echo — reasonable-poly voice avatar

Aster Echo is an original translucent humanoid built for a phone-sized voice interface. Its signal-crest silhouette, paired torso orbits and softly segmented anatomy remain legible at the shipped 384 × 512 px proof size. The runtime assets are [VRM 1.0](aster-echo.vrm) and animation-bearing [glTF binary](aster-echo.glb); the editable source is [aster-echo.blend](aster-echo.blend).

## Runtime budget

| item | measured value |
|---|---:|
| triangles, VRM and GLB | 28,080 |
| humanoid bone mappings | 55 |
| `textures/holo-grid.png` | 256 × 256 px, 2,168 bytes |
| `aster-echo.blend` | 571,501 bytes |
| `aster-echo.vrm` | 1,238,220 bytes |
| `aster-echo.glb` | 1,355,948 bytes |
| `proof/turntable.gif` | 549,925 bytes |

The geometry starts from self-authored anatomical proportion stations. Each station scales an original, clean fixed-topology UV-sphere base cage; lower-density cages form the signal crest and controlled torus topology forms the orbits. Those base cages are the final retopology, keeping the result inside the 20,000–50,000 triangle budget without a hidden sculpt. The only texture is a generated 256 px scan grid, below the 2048 px limit.

## Rig and state clips

The VRM 1.0 map covers the required body bones, eyes, jaw, toes and all finger chains. Bone names follow the `mixamorig:` convention so external Mixamo-named motion can be retargeted by name. All clips are armature Actions at 24 fps and are included in the GLB.

| state-machine clip | frames | behavior | boundary |
|---|---:|---|---|
| `sit` | 1–36 | standing to seated | ends at `rest` pose |
| `stand_up` | 1–36 | seated to standing | inverse endpoints of `sit` |
| `idle_breathing` | 1–72 | subtle chest breath | seamless loop |
| `listen` | 1–48 | attentive head and torso tilt | returns to standing |
| `talk_beats` | 1–60 | alternating conversational hand beats | returns to standing |
| `nod` | 1–42 | two-beat agreement nod | returns to standing |
| `shrug` | 1–48 | bilateral shoulder and palm lift | returns to standing |
| `think` | 1–60 | hand-to-temple and head tilt | returns to standing |
| `rest` | 1–72 | seated breathing | seamless seated loop |

`verify_blend.py` reloads the committed source, checks all nine Actions and 55 bones, and numerically compares the loop and transition boundary matrices to detect popping.

## Rebuild and verification

Run from the repository root:

```sh
./avatar/reasonable-poly/build.sh
```

The build enters the pinned Nix tool environment, regenerates the texture, source, exports and proofs with Blender 5.0.1 on CPU, and reloads the VRM through three's `GLTFLoader` with three-vrm's `VRMLoaderPlugin`. It then loads every GLB clip through `AnimationMixer`, checks the triangle budget and morph displacement, and attempts a software GL context before falling back to structural render assertions when one is unavailable.
