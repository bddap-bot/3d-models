# Contract

Every model ships its STL and a preview PNG, regenerated by `./build` and gated by CI.

## Layout

- One directory per model, `model.json` next to (or above) its `.scad`. `./build` finds every `model.json`.
- `./build` writes `<model dir>/out/<part>.stl` and `<model dir>/out/<part>.png`, one pair per part, and deletes anything else in `out/`. Commit what it writes.
- Anything else in a model directory is that model's own record and is not gated.

## Manifest

```json
{
  "source": "hopper.scad",
  "parts": {
    "assembly": { "camera": [65, 0, 35] },
    "lid": {},
    "tray": { "define": { "part": "tray", "fn": 64 } }
  }
}
```

- `source`: the `.scad`, relative to the manifest.
- `parts`: one entry per exported part, keyed by name (`[A-Za-z0-9_]+`).
  - `define` (optional): `-D` variables for the export; default `{"part": "<name>"}`.
  - `camera` (optional): view rotation `[rotx, roty, rotz]` in degrees; default `[55, 0, 25]`. The preview is the exported STL, auto-centred and fitted, 1200×900.

Any other key, type, or an empty `parts` fails the build.

## Gate

`./build` runs OpenSCAD 2021.01 from the nixpkgs revision pinned in `shell.nix` (the script's shebang enters that shell). STL export is byte-stable on that version, so a stale or missing STL shows up as a git diff. A preview is rewritten only when it differs from a fresh render by RMSE > 0.005 (`magick compare`); a 0.2 mm wall change measures ≈0.015, renderer noise on one machine measures 0. CI runs `./build` on every push and pull request and fails if the tree is not clean afterwards.

## Adding a model

1. Create the directory, the `.scad`, and `model.json`.
2. `./build`, commit the source, manifest, and `out/`.
3. Add the model to the root `README.md` catalog.
